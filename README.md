# Sistema de Autenticação Personalizado 🔐

Este repositório contém uma interface completa de autenticação desenvolvida com **HTML5, CSS3 e JavaScript puros (Vanilla JS)**. O projeto foca em uma experiência de usuário (UX) fluida e um design moderno e responsivo.

## 🚀 Telas Inclusas

* **Login:** Interface intuitiva para autenticação de usuários.
* **Cadastro Completo:** Formulário estruturado para coleta de dados de novos usuários.
* **Recuperação de Senha:** Fluxo personalizado para redefinição de acesso.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização personalizada, utilizando Flexbox/Grid para responsividade.
* **JavaScript (ES6+):** Validação de campos, manipulação de eventos e lógica de interface.
